# Physics Simulations & Teaching Tools

A collection of Python scripts and simulation tools dedicated to physics research and education.

## Contents

1. **`App_DeadTime.py`**: Virtual experiment design for determining the pulse processing time characteristics of nuclear radiation measurement systems (to be published).
2. **`Nuclear_Decay`**: Simulation software for nuclear decay phenomena intended for educational purposes. (https://drive.google.com/file/d/1kDTJHx3dE36CrEwyUzyTn6DIl4MXNlvZ/view)
3. **`walton.py`**: Simulation of the voltage multiplication mechanism of a Walton-Cockcroft accelerator for teaching purposes. (https://drive.google.com/file/d/13S-glfNi4IaSShBIN7eESuhS_GRI7jPx/view)
